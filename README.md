# api-test (React + Vite)

Aplicação React que consome a **CoinGecko API**.

Documentação completa do trabalho (critérios + análise + demonstração): veja o `README.md` na raiz do repositório.

## Como rodar

```bash
npm install
npm run dev
```

## Variáveis de ambiente (opcional)

Copie `.env.example` para `.env.local` e preencha:
- `VITE_COINGECKO_API_KEY`
- `VITE_COINGECKO_BASE_URL` (padrão: `/coingecko/api/v3`)
